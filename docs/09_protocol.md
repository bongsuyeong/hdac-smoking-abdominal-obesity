# 9주차 프로토콜 수정본: 4팀 (현재흡연 → 복부비만)

> 9주차 Issue 검토의견 반영본. 변수명·코드값·결측 현황·인원 수는 원시자료(`HN24_ALL.sav`, 6,997행 × 813열)를 직접 열어 확인했다. 코드의 **문구**와 **쪽수**는 『국민건강영양조사 제9기(2022-2024) 원시자료 이용지침서』(2026년 7월 수정판)와 대조해 채웠다. 아래 `p.○○`는 지침서 **쪽 아래에 인쇄된 쪽번호** 기준이다(PDF 뷰어 쪽수 = 인쇄 쪽번호 + 8).

## 1. 연구질문 (PECO)
* **연구질문:** 대한민국 성인(만 20세 이상)에서 현재흡연이 복부비만과 관련이 있는지 알아보기 위해, 현재흡연군과 비흡연군의 복부비만 유병률을 비교한다.
* **대상 (P):** 2024년 국민건강영양조사 참여자 중 만 20세 이상 성인
  * 지침서의 성인 지표(예: 성인 비만 유병률)는 19세 이상 기준이나(p.42), 본 연구는 만 20세 이상으로 정한다.
* **노출 (E):** 현재 일반담배(궐련) 흡연 = `BS3_1` 1(매일피움) 또는 2(가끔피움) (문항: "현재 일반담배(궐련)를 피우십니까?", p.156~157)
  * 전자담배는 기본 정의에 **포함하지 않는다**. 액상형 전자담배 현재사용(`BS12_2`, 1 예 / 2 아니오)·궐련형 전자담배 현재사용(`BS12_47`, 1 매일피움 / 2 가끔피움 / 3 과거엔 피웠으나 현재 피우지 않음)이 있으므로(p.158-159) 민감도 분석에서 포함 여부를 비교한다. 전자담배만 쓰는 사람은 기본 정의에서 비교군(비흡연군)에 들어가므로, 민감도 분석에서 이들을 제외한 결과도 함께 본다.
  * **지침서 공식 현재흡연율과의 차이:** 지침서의 현재흡연율은 "평생 5갑(100개비) 이상 피웠고 현재 피우는 분율"이다. 즉 `BS1_1` = 2 이면서 `BS3_1` = 1·2 (p.42, 표 18). 본 프로토콜은 `BS3_1` = 1·2 만으로 정의하므로, `BS1_1` = 1(5갑 미만)이면서 `BS3_1` = 2(가끔피움)인 7명이 추가로 현재흡연군에 들어간다. 이 차이는 민감도 분석(공식 정의 적용)에서 확인한다. (최종 분석 대상 5,629명 중 공식 정의의 현재흡연자는 758명, 본 정의는 765명이다.)
* **비교 (C):** 비흡연군 = 과거흡연자(`BS3_1` = 3) + 평생 비흡연자(`BS3_1` = 8, 성인에서는 `BS1_1` = 3 "피운 적 없음"과 완전히 일치)
* **응답 처리 기준 요약:** `BS3_1` = 8(비해당)은 성인에서 평생 비흡연자이므로 결측이 아니라 비흡연(0)으로 분류한다. `BS3_1` = 9(모름·무응답)와 결측은 노출을 정의할 수 없어 분석 대상에서 제외한다.
* **결과 (O):** 복부비만 (허리둘레 `HE_wc`: 남성 ≥ 90cm, 여성 ≥ 85cm)
  * 지침서에는 복부비만 기준이 없고 허리둘레 측정값(cm, p.179)만 제공된다. 90cm·85cm 기준은 대한비만학회 기준이며, 출처 문헌은 팀에서 확인해 11주차 이후 보고서에 인용한다.
* **가설 및 방향:** 현재흡연군은 비흡연군에 비해 복부비만 유병 위험이 높을 것이다.
* **해석 주의:** 횡단면 자료이므로 관찰된 연관성이 인과 효과를 의미하지 않는다. 연령·성별·음주·신체활동 등 교란 가능성은 11주차 DAG에서 판단한다.

## 2. 사용 자료 및 가중치
* **자료:** 2024년 국민건강영양조사 제9기 3차년도 (`year` = 2024, 원시자료 `HN24_ALL.sav`)
* **가중치:** `wt_itvex` (지침서 변수 설명: "건강설문-검진조사 가중치", p.94. 원시자료 변수 라벨은 "건강설문, 검진조사 가중치")
  * 기존 `wt_itv`는 이 자료에 존재하지 않는 변수명이다. 2024년 건강행태조사·검진조사 가중치는 모두 `wt_itvex`이다(표 6-1, p.26).
* **선택 이유:** 결과변수(허리둘레)는 검진조사 측정값이고 노출·공변량(흡연·음주·신체활동 등)은 건강설문조사 문항이다. 여러 조사 부문의 변수를 함께 쓸 때는 모든 변수가 속한 부문을 포괄하는 연관성분석 가중치를 써야 하며(p.24), 2024년 "건강설문 AND 검진" 조합의 가중치는 `wt_itvex`이다(표 6-2, p.28). 영양조사 변수는 쓰지 않으므로 `wt_tot`은 쓰지 않는다.
* **층·집락·가중치 변수:** 층 `kstrata` (101~127, p.94), 집락 `psu` (조사구번호, 문자형, p.93), 가중치 `wt_itvex`. 복합표본 분석 시 층과 집락을 함께 반영하도록 권고한다(p.35). 세 변수 모두 결측 없음. 최종 분석 대상 5,629명 모두 `wt_itvex` > 0이다.
* **분석 방식:** 행을 삭제하지 않고 분석 대상 표시변수(`in_analysis = 1`)를 만들어 도메인 분석으로 설계 기반 SE를 계산한다. 성인 중 허리둘레가 결측인 172명도 `wt_itvex` 값을 갖고 있으므로, 행을 지우면 설계가 달라진다.

## 4. 분석 대상 선정 계획 (대상자 흐름도)
원시자료 기준으로 계산한 인원이다. 노트북 출력과 반드시 일치시킨다.

1. 2024년 국민건강영양조사 전체 참여자 (N = 6,997)
2. 만 20세 미만 제외 (제외 n = 995) → 성인 (N = 6,002)
3. 노출 정의 불가 제외: `BS3_1` = 9 (216) 및 결측 (2), 합계 218 → 노출 정의 가능 (N = 5,784)
4. 결과 정의 불가 제외: `HE_wc` 결측 155 (성인 결측 172명 중 17명은 3단계에서 이미 제외) → **최종 분석 대상 (N = 5,629)**: 현재흡연군 765명, 비흡연군 4,864명

* 공변량 결측은 제외하지 않고 Table 1의 해당 행에 결측 수로 표기한다. 공변량 결측 수는 최종 분석 대상(N = 5,629) 기준으로 다시 센다.
* 최종 분석 대상에게 `in_analysis = 1`을 부여하고, 층·집락 구조가 유지되도록 도메인으로 분석한다.
* **검증:** 위 인원(6,997 → 6,002 → 5,784 → 5,629, 현재흡연군 765 / 비흡연군 4,864), 3번 표의 코드별 빈도·결측 수, `BS3_1` ↔ `BS1_1`, `BD1_11` ↔ `BD1` 교차표 일치, `HE_wc` 특수코드 없음, `psu` 191개 집락·`kstrata` 27개 층을 `hn24.sav`로 다시 계산해 모두 일치함을 확인했다. 10주차 흐름도는 9주차와 달라진 인원이 없다.
* 순서: 원자료 불러오기 → 원 코드 빈도표 확인 → 재코딩 → 재코딩 교차표 확인 → 대상 선정.
* 참고: 최종 대상에서 현재흡연군은 남성 636명, 여성 129명으로 성별 분포가 크게 다르다. Table 1과 해석에서 성별 교란에 주의한다.
