# 9주차 프로토콜: 4팀 (현재흡연 → 복부비만)

## 1. 연구질문 (PECO)
* **연구질문:** 대한민국 성인(만 20세 이상)에서 현재흡연이 복부비만과 관련이 있는지 알아보기 위해, 현재흡연군과 비흡연군의 복부비만 유병률을 비교한다.
* **대상 (P):** 2024년 국민건강영양조사 참여자 중 만 20세 이상 성인
* **노출 (E):** 현재 일반담배(궐련) 흡연 = `BS3_1`이 1(매일) 또는 2(가끔)
  * 전자담배는 기본 정의에 포함하지 않으며, 액상형 현재사용(`BS12_2`)·궐련형 현재사용(`BS12_47`) 변수는 민감도 분석에서 포함 여부를 비교함.
* **비교 (C):** 비흡연군 = 과거흡연자(`BS3_1 = 3`) + 평생 비흡연자(`BS1_1 = 3` 또는 `BS3_1 = 8` / 이용지침서 기준 비흡연 코드)
* **결과 (O):** 복부비만 (허리둘레 `HE_wc`: 남성 ≥ 90cm, 여성 ≥ 85cm)
* **가설 및 방향:** 현재흡연군은 비흡연군에 비해 복부비만 유병 위험이 높을 것이다.
* **해석 주의:** 횡단면 자료이므로 관찰된 연관성이 인과 효과를 의미하지 않는다. 연령·성별·음주·신체활동 등 교란 가능성은 11주차 DAG에서 판단한다.

## 2. 사용 자료 및 가중치 
* **사용 자료 및 연도:** 2024년 국민건강영양조사 (KNHANES IX-2)
* **선택한 가중치:** 검진 가중치 (`wt_itv`)
* **가중치 선택 이유:** 결과변수인 복부비만(허리둘레 `HE_wc`)이 신체계측(검진)을 통해 직접 측정된 변수이므로 검진 가중치(`wt_itv`)를 적용함.
* **층 및 집락 변수:** 
  * 층(Strata): `kstrata`
  * 집락(PSU): `psu`
  * 가중치(Weight): `wt_itv` (지침서 검진 가중치)

## 4. 분석 대상 선정 계획
1. **1단계:** 2024년 국민건강영양조사 조사 참여자 전체 (N = 전체 관측 수)
2. **2단계:** 20세 미만 소아·청소년 제외 (`age >= 20`)
3. **3단계:** 노출(`BS3_1`) 및 결과(`HE_wc`) 무응답·결측치 제외 $\rightarrow$ **최종 분석 대상(`in_analysis = 1`) 확정**
4. **결과 결측 처리 원칙:** 공변량(소득, 학력, 음주, 신체활동)에 결측이 있는 대상자는 분석 대상에서 제외하지 않고, 설계 기반 분석(`domain`)을 유지하며 Table 1 해당 변수 행에 결측 수를 적음.
